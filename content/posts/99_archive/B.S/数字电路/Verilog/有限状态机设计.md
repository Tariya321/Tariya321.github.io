- FSM是描述有限个状态及状态的转移和动作等行为的数学模型
- FSM的组成：输入、输出、状态寄存器
    - 状态寄存器用于记忆有限状态机的内部状态
    - 次态不仅与输入信号有关，而且还与该寄存器的当前状态有关
- 设计FSM的核心在于状态图
- FSM的优点
    - 易于构成良好的同步时序模块，利于解决竞争-冒险
    - 状态切换只需一个时钟周期，可并行运行
    - 可靠性。容错设计，跳出非法状态并切入正确状态，只需要两个时钟周期

> Finite State Machine, FSM，有限状态机
> 现态：current_state
> 次态：next_state

## 1. Mealy型
- 输出是当前状态和输入的函数
- 输出的改变无需等到时钟到来
- 输出速度：Mealy>Moore

## 2. Moore型
- 输出仅是当前状态的函数，即在一个状态下输出是一定的
- 时钟到来，输出才能改变
- 状态个数：Moore>Mealy

## 3. 时间尺度
- `ˋtimescale<时间单位>/<时间精度>`  命令作用于该命令之后的模块
    - 时间单位：仿真/延迟时间的基准单位
    - 时间精度：时间单位的精确程度（表示四舍五入到第几位）
    
示例
- `ˋtimescale 1ns/1ps`：时间精确到0.001ns，可以是1.001ns
- `ˋtimescale 1ns/10ps`：时间精确到0.01ns，可以是1.01ns
> 应注意，时间精度不得大于时间单位

## 4. 综合实例
### 4.1. Moore型FSM
![|450](/attachment/386731723236664.png)
```verilog
module moore_Myinstance(clk, din, op);
input clk, din;
output op;
reg op;

parameter s0 = 2'b00;
parameter s1 = 2'b01;
parameter s2 = 2'b10;
parameter s3 = 2'b11;

reg[1:0] current_state;
reg[1:0] next_state;

always @(posedge clk)
    current_state <= next_state;
    
always @(din, current_state)
    begin
        case(current_state)
        s0:begin
            if(din == 0)
                next_state = s0;
            else
                next_state = s1;
            op = 0;
        end
        s1:begin
            if(din == 0)
                next_state = s1;
            else
                next_state = s2;
            op = 0;
        end
        s2:begin
            if(din == 0)
                next_state = s2;
            else
                next_state = s3;
            op = 1;
        end
        s3:begin
            if(din == 0)
                next_state = s1;
            else
                next_state = s0;
            op = 0;
        end
        default:begin
            next_state = s0;
            op = 0;
        end
        endcase
    end
endmodule
```

### 4.2. Mealy型FSM
![|475](/attachment/216891823256830.png)
```verilog
module mealy_Myinstance(din, op);
input clk, din;
output op;
reg op;

parameter s0 = 2'b00;
parameter s1 = 2'b01;
parameter s2 = 2'b10;
parameter s3 = 2'b11;

reg[1:0] current_state;
reg[1:0] next_state;

always @(posedge clk)
    current_state <= next_state;
    
always @(din, current_state)
    begin
        case(current_state)
        s0:begin
            if(din == 0)begin
                next_state = s0;
                op = 0;
            end
            else begin
                next_state = s1;
                op = 0;
            end
        end
        s1:begin
            if(din == 1)begin
                next_state = s1;
                op = 1;
            end
            else begin
                next_state = s2;
                op = 0;
            end
        end
        s2:begin
            if(din == 1)begin
                next_state = s2;
                op = 0;
            end
            else begin
                next_state = s3;
                op = 1;
            end
        end
        s3:begin
            if(din == 1)begin
                next_state = s0;
                op = 1;
            end
            else begin
                next_state = s1;
                op = 0;
            end
        end
        default:begin
            next_state = s0;
            op = 0;
        end
        endcase
    end
endmodule
```
