## 1. yazi
一款在终端实现文件浏览的tool

配置yazi
```shell
wget https://github.com/sxyazi/yazi/releases/download/v25.3.2/yazi-x86_64-unknown-linux-gnu.zip
unzip yazi-x86_64-unknown-linux-gnu.zip
cd yazi
mv ya* ~/.local/bin
```

check status
```
yazi --version
```

return 
```
# yazi
yazi: /lib64/libc.so.6: version `GLIBC_2.38' not found (required by yazi) 
```
原因+方案：[这里](https://github.com/sxyazi/yazi/issues/2346)，使用musl版本的build

```shell
wget https://github.com/sxyazi/yazi/releases/download/v25.3.2/yazi-x86_64-unknown-linux-musl.zip
unzip xxx.zip
mv ~/xxx/ya* ~/.local/bin
```

```
yazi --version
```
return
```
Yazi 25.3.2 (VERGEN_IDEMPOTENT_OUTPUT 2025-03-02)
```

设置默认变量到bashrc
```
export EDITOR=nvim
export VISUAL=nvim
```
使得yazi可以使用nvim打开编辑器
>写入bashrc可以永久编辑了

## 2. fasd
`fasd`支持便捷的跳跃
```shell
z <your_path_keyword>

# such as
z ising
z case

# show recorded file/location list
fasd -l
```

安装fasd（no sudo）
```shell
mkdir -p ~/.local/bin
curl -L https://raw.githubusercontent.com/clvv/fasd/master/fasd -o ~/.local/bin/fasd
chmod +x ~/.local/bin/fasd
echo 'eval "$(fasd --init auto)"' >> ~/.bashrc
source ~/.bashrc
```

## 3. btop
更炫酷的top工具
安装`btop`

use `wget`
```shell
wget https://github.com/aristocratos/btop/releases/download/v1.4.0/btop-x86_64-linux-musl.tbz

tar xvjf xxx.tbz

# move the binary file to ~/.local/bin
```


or use `conda`
先修改conda镜像为清华源
```shell
conda install -c conda-forge btop
```

```
conda install -c conda-forge tmux
```



## 4. neovim

for user who has no sudo
- use public build
```shell
wget https://github.com/neovim/neovim/releases/latest/download/nvim-linux64.tar.gz

tar xzf nvim-linux64.tar.gz

# 移动 Neovim 可执行文件到本地 bin 目录
mv nvim-linux64/bin/nvim $HOME/bin/

# 清理不必要的文件
rm -rf nvim-linux64 nvim-linux64.tar.gz

# 确保 bin 目录在 PATH 变量中
echo 'export PATH=$HOME/bin:$PATH' >> ~/.bashrc
source ~/.bashrc
```
- build by yourself
```shell
# install dependency
git clone https://github.com/neovim/neovim.git
cd neovim

make CMAKE_BUILD_TYPE=Release
make install PREFIX=$HOME/.local
echo 'export PATH=$HOME/.local/bin:$PATH' >> ~/.bashrc
source ~/.bashrc
```

nvim 的配置文件位置
```
~/.config/nvim/init.vim
```


for conda user
```
conda install -c conda-forge neovim
```

for users for has older GLIBC version, you may met these messages:
```
/lib64/libstdc++.so.6: version `GLIBCXX_3.4.29' not found
```

for older glibc version, please install from "https://github.com/neovim/neovim-releases"
```shell
wget https://github.com/neovim/neovim-releases/releases/download/v0.10.4/nvim-linux-x86_64.tar.gz

tar zxvf nvim-linux-x86_64.tar.gz
mv nvim-linux-x86_64/bin/nvim ~/.local/bin/
echo 'export PATH=$HOME/.local/bin:$PATH' >> ~/.bashrc
```
