## 2. 阻塞和非阻塞区别

非阻塞性赋值：块语句结束后才完成赋值操作，意味着当前块中的多条语句不存在上下关系（类似于并行关系），上面的赋值语句并不能作用在下面的赋值语句中。
$$
Y<= X ;
$$
阻塞性赋值：执行即生效，并且只有当所有赋值语句结束后，块才结束（类似于上下顺序关系）
$$
Y = X;
$$

---
警示

在描述组合逻辑的 always 块中用阻塞赋值，则综合成组合逻辑的电路结构。
在描述时序逻辑的 always 块中用非阻塞赋值，则综合成时序逻辑的电路结构

## 5. Verilog模块编程的八大要领

1) 时序电路建模时，用非阻塞赋值。
2) 锁存器电路建模时，用非阻塞赋值。
3) 用 always 块建立组合逻辑模型时，用阻塞赋值。
4) 在同一个 always 块中建立时序和组合逻辑电路时，用非阻塞赋值。
5) 在同一个 always 块中不要既用非阻塞赋值又用阻塞赋值。
6) 不要在一个以上的 always 块中为同一个变量赋值。
7) 用$strobe 系统任务来显示用非阻塞赋值的变量值
8) 在赋值时不要使用 #0 延迟

## 2. pipeline技术
>技术参见夏宇闻版本 P107，设计实例参见西电版本 P187

所谓流水线设计实际上就是把规模较大、层次较多的组合逻辑电路分为几个级，在每
一级插入寄存器组暂存中间数据。K 级的流水线就是从组合逻辑的输入到输出恰好有K 个
寄存器组（分为 K 级，每一级都有一个寄存器组）上一级的输出是下一级的输入而又无反馈的电路。

首次延迟（latency）：将最长路径进行初始化所需要的时间总量
吞吐延迟（throughput latency）：执行重复操作所需要的时间总量

采用流水线设计的优势在于它能提高吞吐量（throughput)
流水线设计在性能上的提高是以消耗较多的寄存器资源为代价的

寄存器触发时间 $T_{co}$

{{< figure src="/attachment/%E7%BB%84%E5%90%88%E9%80%BB%E8%BE%91%E8%BD%AC%E5%8C%96%E4%B8%BA%E6%B5%81%E6%B0%B4%E7%BA%BF%E8%AE%BE%E8%AE%A1.png" alt="组合逻辑转化为流水线设计" width="300" >}}

流水线设计的**首次延时**相较于纯组合逻辑没有任何优势

但是在触发时间可预测且小于传播延时的前提下，流水线设计的**吞吐延迟**大幅优化

设计|首次延时|吞吐延时
--|--|--
纯组合逻辑|2t_pd|2t_pd
pipeline设计|2(t_pd+t_co)|t_pd+t_co

参见[2015Sp-CS61C-L13-kavs-Pipelining-1up.pdf (berkeley.edu)](https://inst.eecs.berkeley.edu//~cs61c/sp15/lec/13/2015Sp-CS61C-L13-kavs-Pipelining-1up.pdf)
{{< figure src="/attachment/%E6%B5%81%E6%B0%B4%E7%BA%BF%E6%8A%80%E6%9C%AF%E7%A4%BA%E6%84%8F%E5%9B%BE.png" alt="流水线技术示意图" width="425" >}}

联想一下：工场流水线，相当于上游和下游同时执行，一种机器执行一种任务，于是它总是被处理任务所占满的。

如果没有流水线，那么重复操作（吞吐延时）必须等待数据已经进入最后一级电路并完成输出后才能进行下一次工作，否则数据是紊乱的。

节拍！

设计要点：
>当用Verilog 语言描述流水线结构的运算部件时，要使用结构描述，才能够真正综合成设计者想要的流水线结构。简单的运算符表达式只有在综合库中存有相应的流水线结构的宏库部件时，才能综合成流水线结构从而显著地提高运算速度。

## 3. FIFO设计
>first in first out, FIFO先进先出

*这里是一份网页版的[指引](https://www.runoob.com/w3cnote/verilog-tutorial.html)*

- 只能顺序读写，不同于存储器可以按地址读写
- 没有外部读写数据线，可以使用两个时钟分别完成写操作和读操作

先进先出的数据缓存器，通常用于接口电路的数据缓存，
解决了速率匹配、数据缓冲和总线匹配等芯片间通信的问题

（1）对连续的数据流进行缓存，防止在进机和存储操作时丢失数据；

（2）数据集中起来进行进机和存储，可避免频繁的总线操作，减轻CPU的负担；

（3）允许系统进行DMA操作，提高数据的传输速度。这是至关重要的一点，如果不采用DMA操作，数据传输将达不到传输要求，而且大大增加CPU的负担，无法同时完成数据的存储工作。

FIFO 存储器一般可分为同步 FIFO 存储器、异步 FIFO 存储器和双向 FIFO 存储器三种

深度：FIFO所能容纳的最大信号数量

### 3.2. 理解先进先出的机制

{{< figure src="/attachment/FIFO%E7%9A%84%E8%AF%BB%E5%86%99%E8%BF%87%E7%A8%8B.png" alt="FIFO的读写过程" width="500" >}}

- 当我们设置 N 位位宽的时候，读写指针的位宽便是 N + 1
- 此外，读空状态为写指针等价读指针
- 写满状态是两个指针方向一致（异或状态），然后地址一致

一般有两种方法检测：

（1）Extra bit
一般情况下深度为N=2^n的FIFO其地址的位宽为n，其读写地址的位宽也为n。共有N个存储单元，若数据位宽为W则该FIFO的容量即为N✖W　bit。

现在在指针中添加额外的位（extra bit，即地址的MSB）变为n＋１bit，该extra bit用于指示写指针是否递增并越过最后一个FIFO地址，若越过则将该MSB加1，其它位清零。对读指针也进行同样的操作。如对于深度为8的FIFO，需要采用３＋１bit是计数器：0000-1000、1001-1111，MSB作为折回标志，而低3位作为地址指针。

那么判断机制为：

如果两个指针的MSB不同，就说明写指针比读指针多折回一次：如r_addr=0000,且w_addr=1000,为满；

如果两个指针的MSB相同，就说明两个指针折回次数相等。再者其余位相等（则说明FIFO为空。

这个方法增加一位数据的开销来获得判断。

## 4. RISC-V
>Reduced Instruction Set Computer, RISC，即精简指令集计算机

复杂数字系统的设计步骤
如后仿真中发现有错误，可先降低测试信号模块的主时钟频率，如该问题解决了，则需要找到造成问题的关键路径，下一次在布局布线时应先布关键的路径（即在约束文件中注明该路径是关键路径后，再重做自动布局布线），若还有问题则需检查各模块中是否有个别模块没有按照同步设计的原则。若是，则需改写有关的VerilogHDL模块。重复以上工作，直到后仿真正确无误。


RISC-V的组成部件

1)时钟发生器、2)指令寄存器、3)累加器、4)RISC CPU算术逻辑运算单元、5)数据控制器、6)状态控制器、7)程序计数器、8)地址多路器
