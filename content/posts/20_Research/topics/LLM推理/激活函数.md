## 1. What Is an Activation Function?

激活函数是神经网络中用于处理神经元输出的数学函数。它通常应用在线性变换之后。例如下图中的  $f$ 就是激活函数
{{< figure src="/attachment/%E6%BF%80%E6%B4%BB%E5%87%BD%E6%95%B0.png" alt="激活函数" width="191" >}}


Why are activations required in NN?
- 任何线性函数的线性组合仍然是线性的
- 激活函数为网络加入非线性能力，从而拟合复杂函数

## 2. 激活函数的类别


Most commonly used

| Activation        | Formula                          | Range                | Common Use                   |
| ----------------- | -------------------------------- | -------------------- | ---------------------------- |
| Identity (Linear) | $f(x)=x$                         | $((-\infty,\infty))$ | Regression output            |
| Binary Step       | (f (x)=1) if (x>0), else 0        | {0,1}                | Classical perceptron         |
| Sigmoid           | $(\sigma(x)=\frac{1}{1+e^{-x}})$ | (0,1)                | Binary classification output |
| Tanh              | $\tanh(x)$                       | (-1,1)               | Older RNNs                   |
| ReLU              | $\max(0,x)$                      | $[0,∞)$              | Standard hidden layers       |
| Leaky ReLU        | $\max(\alpha x,x)$               | $((-\infty,\infty))$ | Avoid dead ReLUs             |
| PReLU             | $\max(ax,x)) (learnable (a)$     | $((-\infty,\infty))$ | CNNs                         |
| RReLU             | Randomized Leaky ReLU            | $((-\infty,\infty))$ | Regularization               |
| ReLU6             | $\min(\max(0,x),6)$              | [0,6]                | MobileNet                    |

In majority of use:

| Task                              | Typical Activation           |
| --------------------------------- | ---------------------------- |
| CNN hidden layers                 | ReLU, Leaky ReLU, GELU, Mish |
| Vision Transformers               | GELU                         |
| Large Language Models             | SwiGLU, GEGLU, GELU          |
| Binary classification output      | Sigmoid                      |
| Multi-class classification output | Softmax                      |
| Regression output                 | Identity (Linear)            |
| Mobile models                     | ReLU6, Hard-Swish            |
| Self-normalizing networks         | SELU                         |


### 2.1. sigmoid

数学表达式

$$
\sigma(x)=\frac{1}{1+e^{-x}}
$$

Sigmoid 函数的特点是可以把任意实数映射到 (0, 1) 之间，形状像一个“S”型的曲线，因此也被称为**S型函数**

### 2.2. softmax
softmax 激活函数的数学表达式为：
$$ \mathrm{Softmax}(x)_i = \frac{e^{x_i}} {\sum_{j=1}^{n} e^{x_j}} $$

https://botpenguin.com/glossary/softmax-function

> [!NOTE] softmax 和sigmoid 的区别
> softmax 算的是单值在所有值中的分布，而 sigmoid 则是独立计算每一个数值


### 2.3. ReLU

ReLU（Rectified Linear Unit，修正线性单元），它的表达式是：

$$
ReLU (x)=\max(0,x)
$$

- 通常用于神经网络的隐藏层，不是用来直接表示概率



### 2.4. tanh

Tanh（双曲正切）激活函数的表达式是：

$$
\tanh(x)=\frac{e^{2x}-1}{e^{2x}+1}
$$

> [!NOTE] 和 sigmoid 的对比
> 输出以 0 为中心，且输出范围为 $[-1, 1]$


### 2.5. GELU

GELU（Gaussian Error Linear Unit，高斯误差线性单元）

- 常见于 Transformer 模型，例如 BERT、GPT 系列
- 输入值不是被硬性“截断”或单纯按比例缩放，而是根据输入在标准正态分布下的累计概率，平滑地决定保留多少

- 一般采用 **tanh 函数**进行简化计算
