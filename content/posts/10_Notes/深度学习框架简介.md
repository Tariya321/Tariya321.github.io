深度学习框架（Deep Learning Framework）为神经网络的构建、训练、推理和部署提供基础软件支持。现代框架通常包含张量计算、自动微分、GPU/TPU 加速、神经网络模块、优化器以及分布式训练等功能。

目前常见的深度学习框架包括 **PyTorch、JAX 和 TensorFlow**。三者都可以完成神经网络训练，但在设计理念、开发体验和应用场景上存在明显差异。

## 1. PyTorch

PyTorch 是目前研究和模型开发中使用非常广泛的深度学习框架，其核心特点是 **易于编写、易于调试，并具有完善的深度学习生态**。

PyTorch 使用 `Tensor` 作为基本数据结构，并通过自动微分机制记录计算过程。例如：

```
import torch

x = torch.tensor([2.0], requires_grad=True)
y = x ** 2
y.backward()

print(x.grad)
```

PyTorch 的主要优势包括：

- API 接近普通 Python，学习成本较低；
    
- 动态计算图便于调试和修改模型；
    
- 提供 `torch.nn`、`torch.optim` 等完整神经网络组件；
    
- 支持 GPU、混合精度和分布式训练；
    
- 与 Hugging Face、TorchVision、Lightning 等生态兼容良好；
    
- 大量开源模型默认提供 PyTorch 实现。
    

因此，如果目标是**快速实现模型、阅读论文代码、调试网络或使用 Hugging Face 模型**，通常优先选择 PyTorch。

---

## 2. JAX

JAX 是 Google 开发的高性能数值计算框架，其编程方式更接近 NumPy，但同时支持自动微分、JIT 编译和硬件加速。

JAX 的核心并不仅仅是神经网络，而是提供一组对 Python 数值程序进行变换的能力：

```
import jax.numpy as jnp
from jax import grad, jit

def f(x):
    return x ** 2

df = grad(f)
fast_f = jit(f)
```

其中常见的程序变换包括：

- `grad`：自动微分；
    
- `jit`：JIT 编译；
    
- `vmap`：自动向量化；
    
- `pmap` / Sharding：多设备并行。
    

JAX 通常通过 **XLA** 将计算编译到 CPU、GPU 或 TPU 上，因此适合大规模科学计算以及高性能机器学习任务。

JAX 的主要特点包括：

- 接近 NumPy 的数值计算接口；
    
- 强调函数式编程和纯函数；
    
- 自动微分与程序变换能力强；
    
- TPU 支持完善；
    
- 适合复杂并行和大规模模型训练；
    
- 常与 Flax、Haiku 等神经网络库配合使用。
    

因此，如果项目需要 **TPU、大规模并行、函数式程序变换或高性能数值计算**，可以优先考虑 JAX。

## 3. TensorFlow

TensorFlow 是 Google 较早推出的深度学习框架，具有完整的训练和部署生态。

TensorFlow 2.x 通常通过 Keras 构建模型：

```
import tensorflow as tf

model = tf.keras.Sequential([
    tf.keras.layers.Dense(128, activation="relu"),
    tf.keras.layers.Dense(10)
])
```

TensorFlow 的优势主要体现在：

- TensorFlow Serving 支持服务器端部署；
    
- TensorFlow Lite 支持移动端和嵌入式设备；
    
- TensorBoard 提供成熟的训练可视化工具；
    
- 具有较完整的工业部署生态。
    

近年来，在深度学习研究和开源模型领域，PyTorch 的使用更加普遍，但 TensorFlow 在部分已有工业系统和端侧部署场景中仍然具有较强影响力。

## 4. PyTorch 与 JAX 的核心区别

|特性|PyTorch|JAX|
|---|---|---|
|编程风格|面向对象 + Python 风格|函数式编程|
|调试体验|较直观|JIT 后调试相对复杂|
|自动微分|Autograd|`grad`|
|编译优化|`torch.compile`|`jit`|
|自动向量化|`vmap`|`vmap`|
|GPU|支持完善|支持|
|TPU|支持有限|支持完善|
|Hugging Face|生态非常成熟|部分模型支持|
|科研模型开发|非常适合|适合|
|高性能数值计算|较强|非常强|

需要注意的是，两者近年来正在逐渐趋同。PyTorch 引入了 `torch.compile`、`vmap` 等机制，而 JAX 生态也提供了越来越完整的神经网络库。


## 5. PyTorch和TensorFlow之对比

Most cases: 用 PyTorch 训练 → 转 TensorFlow → 部署

why?
- PyTorch
	- 动态图，调试方便，研究人员最喜欢
- TensorFlow
	- 在工业界的部署生态比较完善
	- 移动端有专门的 TensorFlow-Lite 提供部署支持
