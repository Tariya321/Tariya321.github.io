## 1. 基础操作与矩阵输入

### 1.1. 基础操作

- MATLAB 可以用作计算器，支持加、减、乘、除、幂运算和平方根函数。
- 常用运算符：+、-、*、/、^、`sqrt()`；反斜杠运算符用于左除。
- 运算遵循优先级规则；不确定时可加括号明确顺序。
- 按 ↑ 键可重新调用此前输入的命令。
- 语句末尾加分号（;）可隐藏输出结果。

### 1.2. 创建矩阵

- 行向量示例：

~~~matlab
a = [1 2 3 4];
a = [1, 2, 3, 4];
~~~

- 矩阵示例：

~~~matlab
A = [1 2 3; 3 4 5; 6 7 8];
~~~

- 使用 `zeros`、`ones`、`rand` 等函数创建数组。例如，创建由零组成的 5×1 列向量：

~~~matlab
z = zeros(5, 1);
~~~

### 1.3. 矩阵运算

- 常见运算：`A + 10`、`sin(A)`、`A'`（转置）、`inv(A)`（求逆）。
- 对数组元素逐个运算时，在运算符前加点，例如 `.*`、`./`、`.^`。
- 水平串联：`A = [a, a]`；垂直串联：`A = [a; a]`。
- 使用 `i` 或 `j` 表示复数的虚数单位。

### 1.4. 换行输入

如果语句太长无法写在一行，可在行末输入三个点（`...`），再继续输入。

## 2. 数组索引

数组索引用于访问数组中的指定元素。以下以矩阵 A 为例：

~~~matlab
A = [1 2 3; 4 5 6; 7 8 9];
~~~

- 指定行列：`A(1, 2)` 访问第一行、第二列的元素。
- 线性索引按列遍历。例如，`A(8)` 的结果为 6。
- 访问不存在的位置会报错。给更大的索引赋值可扩展数组，未赋值的位置填入 0，例如 `A(4, 4) = 10`。
- 使用冒号选择多个元素：
  - `A(1:3, 2)`：前三行、第二列。
  - `A(1, 1:2)`：第一行、前两列。
  - `A(3, :)`：第三行的所有元素。
- 创建等间距向量：`0:10:100` 表示从 0 到 100、步长为 10；省略步长时默认为 1。

## 3. 工作区变量

- 创建变量：`A = zeros(2, 2)`。
- 查看工作区：运行 `whos`，或查看右侧的 Workspace 面板。
- 保存和读取工作区：

~~~matlab
save XX.mat
load XX.mat
~~~

- 清除所有变量：运行 `clear`。

## 4. 文本和字符

### 4.1. 字符串数组（string）

- 字符串文本使用双引号括起。
- 字符串内部需要双引号时，将其写成两个双引号：

~~~matlab
t = "I am a teacher";
q = "He is a ""man"" as you";
~~~

- 此时 t 和 q 都是 1×1 字符串数组。
- 使用 + 在字符串末尾追加文本。
- 使用 `strlength` 函数获取字符串长度。
- 字符串中的特殊字符可使用转义序列表示。

### 4.2. 字符数组（char）

- 字符数组使用单引号括起。
- 示例：

~~~matlab
seq = 'GCTAATCG';
seq(4) = 'A';
~~~

- 两个字符数组可像矩阵一样水平串联：

~~~matlab
seq2 = [seq, 'ATTCGA'];
~~~

## 5. 调用函数

- `max` 返回最大值；指定两个输出参数时，还可同时获得最大值所在的位置：

~~~matlab
A = [1 3 5];
maxA = max(A);
[maxA, idx] = max(A);
~~~

- 函数可以接收多个输入参数，例如 `max(A, B)`。
- `disp('文本')` 用于输出文本。
- `clc` 清空命令行窗口，但不清除变量。

## 6. 编程与脚本

### 6.1. 脚本（`.m` 文件）

1. 使用 `edit` 命令创建脚本，例如 `edit mysphere`。
2. 使用百分号（%）添加注释，例如 % Find the surface and volume.
3. 将脚本保存在当前文件夹或目标文件夹。
4. 确保脚本所在文件夹是当前文件夹或已添加到搜索路径。
   - 在当前文件夹浏览器中选中文件夹，右键选择“添加到路径”。
5. 在命令行输入脚本名称运行，也可点击编辑器中的“运行”按钮。

### 6.2. 实时脚本（`.mlx` 文件）

实时脚本可同时展示代码、输出、格式化文本、方程和图像。

- 新建实时脚本：使用 `edit` 命令并指定 `.mlx` 文件名，例如 `edit myfile.mlx`。
- 将现有脚本转换为实时脚本：另存为 `.mlx` 文件。
- 可把注释转换为格式化文本：选中以百分号开头的行，选择“文本”并删除百分号；也可改写行尾注释。需要公式时，在“插入”选项卡中选择“方程”。

### 6.3. 循环与条件语句

循环使用 `for` 或 `while`，条件语句使用 `if` 或 `switch`。

计算并输出斐波那契数列前十项：

~~~matlab
N = 100;
f(1) = 1;
f(2) = 2;

for n = 3:N
    f(n) = f(n - 1) + f(n - 2);
end

f(1:10)
~~~

按数值范围分类：

~~~matlab
num = randi(100);

if num < 34
    sz = 'low';
elseif num < 67
    sz = 'medium';
else
    sz = 'high';
end
~~~




## 7. 帮助和文档

MATLAB 函数提供辅助文档。以 `mean` 函数为例：

- 打开完整帮助页：`doc mean`。
- 查看命令行帮助：`help mean`。
- 在命令行输入 `mean(` 可查看函数提示。
- 点击“帮助”图标可访问完整产品文档。

## 8. 矩阵和幻方矩阵

- 输入矩阵时，元素之间用空格或逗号分隔，行之间用分号分隔，例如 `[1 2; 3 4]`。
- MATLAB 默认按列处理矩阵。要求各行总和时，可先转置矩阵，再按列求和。
- 两种转置运算符：
  - `A'`：共轭转置。
  - `A.'`：非共轭转置。
- `magic(n)` 用于创建 n 阶幻方矩阵。
- 常见矩阵生成函数：
  - `zeros`：元素全为 0。
  - `ones`：元素全为 1。
  - `rand`：生成均匀分布的随机数。
  - `randn`：生成正态分布的随机数。

## 9. 表达式

### 9.1. 变量和数字

- 变量名区分大小写，由字母、数字和下划线组成，并以字母开头。
- 实数可用科学计数法表示，例如 1.2e3。
- 数值的存储类型决定其精度；`format` 命令只改变显示格式。
- 复数可使用 `i` 或 `j` 表示虚数单位。

### 9.2. 运算符和函数

- 矩阵运算符按矩阵规则运算；数组运算符在对应运算符前加点，例如 `.^`。
- 获取函数列表：`help` elfun（初等函数）、`help` specfun（特殊函数）、`help` elmat（矩阵函数）。

### 9.3. 构建表格

示例一：

~~~matlab
n = (0:9)';
pows = [n n.^2 2.^n];
~~~

示例二：

~~~matlab
format short g
x = 1:0.1:2;
logs = [x log10(x)];
~~~

## 10. 输入命令

- 控制数值显示格式：使用 `format`。
- `sprintf` 和 `fprintf` 可按指定格式生成或输出文本。
- 隐藏语句输出：在语句末尾添加分号。
- 输入长语句：在行末添加三个点（`...`），再换行继续输入。
- 命令行编辑：使用方向键重新调用、编辑和重用历史命令。反复按 ↑ 可浏览上一条命令；输入若干字符后按 ↑ 可查找以这些字符开头的历史命令。

## 11. 二维图和三维图

### 11.1. 二维线图

使用 `plot` 函数绘制 0 到 2π 的正弦曲线：

~~~matlab
x = 0:pi/100:2*pi;
y = sin(x);
plot(x, y);
~~~

- 标记坐标轴并添加标题：

~~~matlab
xlabel('X');
ylabel('Y');
title('Plot of the Sine Function', 'FontSize', 12);
~~~

- 添加图例：`legend('sin', 'cos')`。
- `plot(x, y, 'color_style_marker')` 中，color 表示线条颜色，style 表示线型，marker 表示标记符号。
- 默认情况下，重新绘图会清除当前图像。使用 `hold on` 可在现有图像上继续绘制。

### 11.2. 三维绘图

绘制函数 z = x·e^(-x²-y²)，其中 x 和 y 的取值范围为 [-2, 2]：

~~~matlab
x = linspace(-2, 2, 20);
y = x';
z = x .* exp(-x.^2 - y.^2);
surf(x, y, z);
~~~

使用 `meshgrid` 创建网格坐标：

~~~matlab
[X, Y] = meshgrid(x, y);
~~~

- `meshgrid(x)` 使用 x 生成方形网格；`meshgrid(x, y)` 分别使用 x、y 作为两个坐标轴。
- `mesh` 生成带颜色的网格曲面；`surf` 生成带颜色的曲面。
- MATLAB 当前颜色图控制网格、曲面颜色；面片颜色取决于 z 值。
- 使用 `alpha` 设置曲面透明度，取值为 0（完全透明）到 1（不透明），例如 `alpha(0.4)`。

### 11.3. 多图输出

使用 `figure(n)` 预先指定图窗编号，可按编号创建或切换图窗。

### 11.4. 子图

`subplot` 函数用于在同一图窗的不同区域绘制多个图像。例如 `subplot(2, 2, 1)` 表示将图窗分为 2 行、2 列，并选中第一个区域进行绘图。
